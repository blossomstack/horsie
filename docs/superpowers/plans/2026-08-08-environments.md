# Environments Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `EnvironmentSpec` — an ad-hoc runtime-plus-repos, or a predefined environment by name — the one required answer to "where does this run" on every session-creation path, in the server, the CLI and the web UI.

**Architecture:** A fluorite union lands in `environments.fl`; `build_session_spec` resolves it once at creation and snapshots the result into `SessionSpec`; every creation path (sessions API, agent invoke, routine trigger, workflow run) hands it that union and nothing else. The web UI replaces its Runtime and Repos pickers with one Environment picker rendered through the existing `PickerSpec` mechanism, so all four surfaces share one implementation.

**Tech Stack:** Rust (axum, sqlx `Any`, fluorite codegen via `build.rs`), TypeScript/React (vite, vitest, Playwright), SQLite + PostgreSQL migrations in lockstep.

**Spec:** `docs/superpowers/specs/2026-08-08-environments-design.md`

```
/// Where a session runs and what it runs against. Every creation path takes
/// one, and none of them defaults: an absent environment would be a fifth,
/// invisible way to answer the question the other four answer out loud.
#[type_tag = "type"]
union EnvironmentSpec {
    Runtime(RuntimeEnvironment),
    Named(NamedEnvironment),
}

/// The ad-hoc environment: a runtime vendor, plus the repos to check out into
/// it when it can provision one. A vendor that cannot rejects a non-empty
/// `repos` at create — which is why there is no separate "local" variant.
struct RuntimeEnvironment {
    vendor: String,
    repos: Option<Vec<RepoConfig>>,
}

/// A predefined environment, by name. Resolved and snapshotted at creation, so
/// editing the environment later never re-points a session that already exists.
struct NamedEnvironment { name: String }
```

```rust
    // Resolved once, here, and snapshotted into the spec: `runtime_spec`
    // re-reads this on every create *and* every revive, so a session revived
    // next week gets what it was created with rather than what the environment
    // says today.
    let (vendor, repos, env_vars, extra_steps) = match environment {
        EnvironmentSpec::Runtime(r) => (
            r.vendor,
            r.repos.unwrap_or_default(),
            Vec::new(),
            Vec::new(),
        ),
        EnvironmentSpec::Named(n) => {
            let env = environments.get(&n.name).await.map_err(|e| match e {
                EnvironmentError::NotFound(m) | EnvironmentError::Invalid(m) => {
                    SpecError::Invalid(m)
                }
                EnvironmentError::Conflict(m) | EnvironmentError::Internal(m) => {
                    SpecError::Internal(m)
                }
            })?;
            (env.vendor, env.repos, env.env_vars, env.provision)
        }
    };
    if vendor.trim().is_empty() {
        return Err(SpecError::Invalid(
            "environment names no runtime vendor".to_string(),
        ));
    }
    // Checkouts first, then the environment's own steps: a step like
    // `make setup` needs the repo to be on disk already.
    let provision: Vec<ProvisionStepSpec> = horsie_models::provision_from_repos(&repos)
        .map_err(|e| SpecError::Invalid(format!("invalid repos: {e}")))?
        .into_iter()
        .chain(extra_steps)
        .map(|s| ProvisionStepSpec {
            name: s.name,
            uses: s.uses,
            with: s.with.into_iter().map(|p| (p.key, p.value)).collect(),
        })
        .collect();
```

Capture the environment name before the match (`let environment_name = match &environment { EnvironmentSpec::Named(n) => Some(n.name.clone()), EnvironmentSpec::Runtime(_) => None };`) and set the two new `SessionSpec` fields in the returned literal, replacing `vendor: vendor.unwrap_or_else(...)` with the resolved `vendor`.

- [ ] **Step 1: Write the helper and its tests**

```rust
/// `--environment <name>` or `--vendor <v> [--repo …]`, one required.
///
/// The two flag shapes are the two variants of the union, and naming both is
/// ambiguous rather than a merge: an environment already carries a vendor.
pub fn environment_from_flags(
    environment: Option<String>,
    vendor: Option<String>,
    repos: &[String],
) -> Result<EnvironmentSpec, String> {
    match (environment, vendor) {
        (Some(_), Some(_)) => Err("--environment and --vendor are alternatives; pass one".into()),
        (Some(name), None) if !repos.is_empty() => {
            let _ = name;
            Err("--repo applies to --vendor; a named environment carries its own repos".into())
        }
        (Some(name), None) => Ok(EnvironmentSpec::Named(NamedEnvironment { name })),
        (None, Some(vendor)) => Ok(EnvironmentSpec::Runtime(RuntimeEnvironment {
            vendor,
            repos: (!repos.is_empty()).then(|| {
                repos
                    .iter()
                    .map(|r| RepoConfig {
                        url: r.clone(),
                        git_ref: None,
                        dir: None,
                    })
                    .collect()
            }),
        })),
        (None, None) => Err("pass --environment <name> or --vendor <name>".into()),
    }
}
```
