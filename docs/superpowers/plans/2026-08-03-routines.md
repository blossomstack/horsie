# Routines Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add routines — a saved agent preset plus a fixed prompt and a trigger (button, API, or timer) — whose runs are unattended sessions listed on the routine's own page.

**Architecture:** A `routines` table in the settings DB references an agent preset by name; `SessionSpec` gains a `SessionOrigin` that both hides routine sessions from the session list and strips `ask_user` from them. One `RoutineRunner` serves all three trigger paths; a 15s `RoutineScheduler` tick fires due routines.

**Tech Stack:** Rust (axum, sqlx/SQLite, `horsie-actor`), fluorite schemas → generated Rust + TypeScript, React 19 + react-router + TanStack Query, Vitest + Playwright.

## Global Constraints

- Spec: `docs/superpowers/specs/2026-08-03-routines-design.md`.
- Production code denies `unwrap_used`, `expect_used`, `panic`, `wildcard_enum_match_arm`. Test modules opt out with the crate's existing `#[allow(...)]` header.
- Protocol types are fluorite-generated (`models/fluorite/*.fl`); persisted types are hand-written and must load old rows (`#[serde(default)]`, never a rename).
- Every fluorite change must be regenerated into **both** `clients/ts/src/generated` and `clients/web/src/generated` (CI fails on drift in the former).
- Minimum routine interval: 60 seconds. Scheduler tick: 15 seconds.
- Pre-PR gate: `cargo fmt --all -- --check`, `cargo clippy --all-targets --all-features -- -D warnings`, `cargo test --workspace`, `bun run test:unit`, `bun run build`.

- [ ] **Step 1: Write `routines.fl`**

```
/// Named routines: an agent preset plus a fixed prompt and a trigger.
package routines;

use session.SessionSummary;

/// Triggered only by hand (the web UI button) or by the API.
struct ManualSchedule {}
/// Triggered every `interval_secs` seconds; minimum 60.
struct EverySchedule { interval_secs: u64 }
/// Triggered once, at `at_ms` (unix epoch millis); never re-arms.
struct OnceSchedule { at_ms: u64 }

#[type_tag = "type"]
union RoutineSchedule {
    Manual(ManualSchedule),
    Every(EverySchedule),
    Once(OnceSchedule),
}

struct RoutineView { name, description, agent, prompt, schedule, enabled,
                     next_run_at_ms, last_run_at_ms, last_session_id,
                     last_error, created_at, updated_at }
struct RoutineInput { name, description?, agent, prompt, schedule?, enabled? }
struct RoutineRunResponse { session: SessionSummary }
struct RoutineSessionsResponse { sessions: Vec<SessionSummary> }
```

- [ ] **Step 2: Write the migration**

```sql
CREATE TABLE routines (
    name            TEXT PRIMARY KEY,
    description     TEXT    NOT NULL DEFAULT '',
    agent           TEXT    NOT NULL,
    prompt          TEXT    NOT NULL,
    schedule_kind   TEXT    NOT NULL,   -- manual | every | once
    interval_secs   INTEGER,            -- non-NULL iff every
    at_ms           INTEGER,            -- non-NULL iff once
    enabled         INTEGER NOT NULL DEFAULT 1,
    next_run_at_ms  INTEGER,
    last_run_at_ms  INTEGER,
    last_session_id TEXT,
    last_error      TEXT,
    created_at      TEXT    NOT NULL,
    updated_at      TEXT    NOT NULL
);
```

Run: `make ts-types` and `cd clients/web && bun run generate-types`
