# Plugin MCP Auth Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let a plugin-declared MCP server authenticate — static headers verbatim today, server-brokered OAuth tomorrow — without ever moving the MCP client out of the runtime.

**Architecture:** Placement stays fixed: every plugin-declared server runs in the runtime. The credential travels instead. `HttpTransport` already takes a `BearerProvider`; the runtime's is fed by tokens the server resolves and sends with each `McpDiscover`/`McpInvoke`. A `401` carrying `WWW-Authenticate` is reported back as a typed `NeedsAuth` failure, which the server turns into the Connect flow `server/src/mcp/oauth.rs` already implements.

**Tech Stack:** Rust (tokio, reqwest, sqlx), fluorite schemas → generated TS, React web client, Playwright e2e.

## Global Constraints

- Specs: `docs/superpowers/specs/2026-08-05-plugin-mcp-design.md` and `docs/superpowers/specs/2026-08-06-plugin-mcp-auth-design.md`.
- No backward compatibility is owed. Change wire shapes to the right end state rather than adding a compatible alternative.
- Every `.fl` change must regenerate **both** type trees: `clients/ts/src/generated` and `clients/web/src/generated`. CI drift-checks only `clients/ts`, so `clients/web` must be regenerated by hand or it silently rots.
- Regenerate with `cargo install fluorite_codegen --version =0.6.2`, then `make ts-types`, then `cd clients/web && bun run generate-types`.
- `clients/web` installs with **bun**, never `npm ci`.
- Iterate with `cargo test -p <crate> --lib`; run `make check` once before pushing, never twice in one command.
- Rust wire fields are `snake_case` in `.fl` and reach TypeScript as `camelCase`. A hand-written JSON body using the snake_case spelling is silently ignored, never an error.
- Never `pool().begin()` for a write; always `Db::begin_write()`.

### Task 1: Refuse duplicate MCP server names

**Files:**

- Test: `runtime/src/mcp.rs` (`mod tests`)

/// One declared server and the plugin it came from. The root is kept because
/// `${CLAUDE_PLUGIN_ROOT}` and the child's `CLAUDE_PLUGIN_ROOT` both need it.
pub struct DeclaredServer {
    pub server: PluginMcpServer,
    pub plugin_root: PathBuf,
}

pub fn declared(plugins_dir: &Path) -> (Vec<DeclaredServer>, Vec<McpServerFailure>) {
    let mut out: Vec<DeclaredServer> = Vec::new();
    let mut failures = Vec::new();
    for plugin_root in crate::plugins::plugin_dirs(plugins_dir) {
        match horsie_support::plugin::mcp::read(&plugin_root) {
            Ok(servers) => {
                for server in servers {
                    // First declaration wins, and the loser is named. Silently
                    // merging would hand one plugin another's tool namespace.
                    if let Some(prior) = out.iter().find(|d| d.server.name == server.name) {
                        failures.push(McpServerFailure::Unreachable {
                            server: server.name.clone(),
                            reason: format!(
                                "already declared by {}",
                                prior.plugin_root.display()
                            ),
                        });
                        continue;
                    }
                    out.push(DeclaredServer {
                        server: expand_root(server, &plugin_root),
                        plugin_root: plugin_root.clone(),
                    });
                }
            }
            Err(e) => failures.push(McpServerFailure::Unreachable {
                server: plugin_root.display().to_string(),
                reason: e,
            }),
        }
    }
    (out, failures)
}
```

Update `discover` to iterate `DeclaredServer` and `invoke` to `find(|d| d.server.name == server_name)`.

### Task 5: Discovery that does not stall the turn

- Modify: `runtime/src/mcp.rs`, `mcp-client/src/stdio.rs`
- Test: `runtime/src/mcp.rs`

**Interfaces:**
- Produces: `StdioTransport::spawn(command, args, env, cwd, plugin_root: Option<&Path>)` — the extra argument sets `CLAUDE_PLUGIN_ROOT` in the child, matching `run_hook`.

/// Mirrors the hook and bash clamps. An MCP server is as capable of returning
/// a megabyte as a command is, and the transcript pays for it either way.
const OUTPUT_CLAMP: usize = 50_000;

fn clamp(text: String) -> String {
    if text.len() <= OUTPUT_CLAMP {
        return text;
    }
    let mut cut = OUTPUT_CLAMP;
    while !text.is_char_boundary(cut) {
        cut -= 1;
    }
    format!("{}\n… truncated at {OUTPUT_CLAMP} bytes", &text[..cut])
}
```
